# Strategies Studio — final multipage website

Six static pages adapted from the supplied `index_3.html`, preserving its navy/gold identity, section layouts, particle knight, chessboard, and interactive tools.

- `index.html`: Home, comparison, numbers, and promise
- `services.html`: Six services and implementation approach
- `journey.html`: Interactive employee journey
- `tools.html`: HR health check and attrition calculator
- `about.html`: Company, Studio values, and purpose
- `contact.html`: Consultation form, contact details, and FAQ

Open `index.html` directly, or run `node scripts/preview-site.cjs` from the repository directory and visit http://localhost:3010. Upload this folder's contents together to a static web host. All navigation uses relative URLs.

The contact form prepares a message in WhatsApp or the visitor's email app. It does not send messages automatically or store submissions. Google Fonts requires an internet connection; system font fallbacks are included.

Shared styling and interactions are in `assets/site.css` and `assets/site.js`.
